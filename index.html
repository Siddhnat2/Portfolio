Haven — Offline LLM Assistant with Safety Guardrails

LLM · Safety
A fully local conversational app: no cloud, no data leaving the device.

A desktop chat application that runs a 3B-parameter model through Ollama and keeps every conversation in local SQLite. Small models drift off-prompt within a few turns, so Haven doesn't rely on prompting alone — it wraps the model in layered controls and verifies the output before it reaches the screen.

User message→Crisis check (deterministic)→Intent classifier→Persona + state prompt→Llama 3.2 3B→Output validator→Stream buffer → UI
  • Three-layer prompting: persona constraints, per-message intent classification (venting, help-seeking, reassurance-seeking, etc.) and conversation-state tracking to prevent repetitive or interrogative replies.
  • Output validation: post-processing enforces format rules and automatically regenerates non-compliant responses.
  • Deterministic safety path: crisis language is intercepted by rule-based matching on the UI thread before the model is ever called — a design choice, since a small model should not improvise on high-risk input.
  • Inference tuning: sentence-boundary stream buffering, startup warm-up with keep-alive, and context trimming to bound per-request cost.

MeshForge — Video-to-3D Reconstruction & 3D-Printing Studio

Computer Vision
Turns a video or photos of an object into a watertight, print-ready 3D model.

A desktop and CLI tool that reconstructs objects from ordinary video and exports to the formats 3D-printing and graphics workflows expect.

  • Three reconstruction strategies — visual-hull carving, structure-from-motion and monocular depth — with automatic fallback between them when one fails on a given input.
  • Deep learning + classical CV: MiDaS/DPT depth estimation in PyTorch, ONNX Runtime segmentation, and SIFT + RANSAC pose estimation.
  • Export: STL, 3MF, OBJ, PLY and GLB.
  • Engineered like a product: modular architecture across 44 modules, with 50+ pytest tests.

SmartPost Studio — AI Content Pipeline with Local-Model Fallback

LLM · Automation
From topic to written post, generated image and approved publish — with every step visible.

A cross-platform desktop app that automates a content workflow end to end. It is built so the pipeline never dead-ends: when a cloud quota runs out, it falls back to a local model, and when image generation is unavailable, it produces a branded card instead.

Topic (live tech news / Excel)→Copy: Gemini → Ollama fallback→Image: Gemini / Stable Diffusion / branded card→Backup→Human approval→Publish
  • Resilient LLM routing: Gemini by default, automatic fallback to a local Ollama model on quota errors, or fully local by choice.
  • Human-in-the-loop controls: confirmation before every publish, configurable daily cap, dry-run mode that stops before posting, and a live activity console.
  • Secure by design: API keys held in the OS credential manager (not in the database or plain text); the app never handles account passwords.
  • Pluggable architecture: publisher layer defined as a protocol, so an official API publisher can replace the browser-based one without touching the pipeline.
  • Operations: scheduling queue with autopilot, SQLite history, dated asset backups, Excel topic import, and PyInstaller packaging for Windows, macOS and Linux.
